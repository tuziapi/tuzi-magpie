## 后台查看口径

页面访问使用固定路径和中文标题，不随界面语言变化。例如：
`/agents`（智能体）、`/providers`（服务商）、`/tuzi/keys`（兔子账户 / API 密钥）、
`/tuzi/models`（模型市场）。首次打开和实际切页记一次；轮询、重绘、取消跳转不计数。
托盘不参与统计。UV 使用 Umami 的访客口径，不是账户数，也不跨设备绑定身份。

| 中文事件 | 触发 | 属性 |
| --- | --- | --- |
| 获取系统令牌 | 获取令牌页面打开请求成功 | 无业务参数 |
| 连接兔子账户 | 提交连接、收到结果 | 阶段、结果、错误码 |
| 断开兔子账户 | 断开成功 | 阶段、结果 |
| 创建 API Key | 提交创建、收到结果 | 阶段、结果、错误码 |
| 查看模型详情 | 打开详情 | 无模型名称 |
| 添加服务商 | 兔子账户添加服务商、收到结果 | 阶段、结果、入口、协议、服务商 |
| 接入智能体 | 提交接入、收到结果 | 阶段、结果、智能体、错误码 |
| 断开智能体 | 断开成功（包含离线断开和退出前断开） | 阶段、结果、智能体 |

`阶段` 为“开始 / 结果”，`结果` 为“成功 / 失败 / 待确认”。
查看成功转化时筛选 **阶段=结果、结果=成功**，不能把开始与结果相加当成功次数。
`服务商` 为“新增 / 复用”，`入口` 为“API 密钥 / 模型市场”。
未知智能体和自定义配置档标记为“其他”。错误码只允许固定列表，不上报错误原文。
网络中断、请求取消和后端报告的结果不确定不会算作已知失败。
后端的 `outcomeUnknown: true` 优先于错误码，因此响应解析错误、存储错误等也能正确记为“待确认”。
智能体配置成功不等于模型请求成功；不采集网关请求级事件。

公共属性为版本、系统、模式和语言。事件内容不含账户标识、Token、Key、自定义名称、
搜索词、URL 参数、提示词或日志。SDK 的网络请求仍会向服务器暴露 IP 和来源主机名。

## 开关和失败行为

“设置 → 隐私 → 将我计为用户”关闭后停止统计；关闭使用情况分享后只保留页面访问。
脚本尚未加载时，关闭使用情况分享只清除排队中的自定义事件，保留已排队的页面访问。
同时遵守 `DO_NOT_TRACK`、`MAGPIE_NO_STATS` 和浏览器 DNT。
其他窗口通过已有状态刷新获得设置变化，已经发送的请求不能撤回。
脚本按需加载；加载前最多缓存 50 条，只有内存队列，不落盘、不持续重试。
远程脚本启用 SHA-384 完整性校验和匿名 CORS；内容变化时拒绝执行，避免服务器更新直接替换客户端代码。
升级 Umami 时必须先审查新脚本，同步更新校验值及 `internal/gui/testdata/umami` 测试样本；
未更新校验值的旧版客户端会停止统计，但业务操作仍可用。
加载/上报失败不影响业务操作。不创建账户身份或持久设备 ID 供 Umami 使用。

## 验证

`internal/gui/tests/analytics.test.cjs` 使用真实页面、固定版本 SDK 和模拟网络，覆盖五种语言、
Chromium/WebKit、去重、过滤、开关、队列及失败隔离。
`tuzi-account.test.cjs` 的账户操作用例核对连接、创建 Key、添加服务商的实际事件。
`TestAnalyticsBootHonorsPrivacy` 检查启动配置的隐私设置与环境变量。
测试不向生产 Umami 发送事件。原生 WebView 的线上到达与 Umami 后台展示需独立验收。
